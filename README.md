# my-skills

Claude Code에서 쓰는 개인 스킬 모음입니다.

## todo-summary — 오늘 완료한 할 일을 커밋 메시지 형식으로 요약

### 불편했던 점
하루를 마칠 때마다 AI에게 같은 설명을 반복했습니다.
"todo 앱에서 오늘 완료한 것만 뽑아 줘 → 날짜 붙여서 → 목록 형식으로 → 남은 개수도 알려 줘."
매번 말이 조금씩 달라서 결과 형식도 그때그때 달랐고, AI가 데이터 파일(todo.db)을 직접 열려고 할 때도 있었습니다.

### 스킬로 해결한 것
- 절차와 출력 형식을 `SKILL.md`에 한 번 적어 두어, **"오늘 한 일 정리해 줘" 한마디**로 항상 같은 형식이 나옵니다.
- 데이터는 앱의 CLI(`node bin/todo.js summary`)로만 읽게 해서, 실데이터 파일을 직접 건드리지 않습니다.

### 설치
적용할 Todo 앱 프로젝트 루트에 스킬 폴더를 복사합니다.

```
<Todo 앱>/.claude/skills/todo-summary/SKILL.md
```

전제: 그 프로젝트에 `node bin/todo.js summary` 명령이 있어야 합니다. (명령 경로가 다르면 SKILL.md 1번 줄을 고쳐 쓰세요.)
복사한 뒤 Claude Code를 새로 열어야 스킬이 인식됩니다.

### 호출 문장
- "요약 스킬 써서 오늘 한 일 정리해 줘"
- "오늘 한 일 정리해 줘" / "완료 요약"

### 실제 확인한 결과 (2026-11-02, 새 대화에서 호출)

```
오늘 한 일 (2026-11-02)

- 보고서 초안 쓰기 (#2)

남은 할 일: 2건
```

AI가 요청을 받자 `todo-summary` 스킬을 먼저 불러 본문을 읽고, `node bin/todo.js summary`를 실행(권한 승인 후)해 위 형식으로 정리했습니다.
