# 오늘 완료 요약

1. `node bin/todo.js summary`를 실행한다. todo.db를 직접 열지 않는다.
2. 출력에서 완료 항목만 골라 아래 형식으로 정리한다.

   ```
   오늘 한 일 (YYYY-MM-DD)

   - <할 일 내용> (#번호)
   ```

3. 오늘 완료한 항목이 없으면 "오늘 완료한 할 일이 없습니다."라고만 답한다.
4. 마지막 줄에 "남은 할 일: N건"을 덧붙인다.
